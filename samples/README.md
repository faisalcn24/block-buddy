# Selected implementation samples

These files are a small, non-sensitive cross-section of BlockBuddy's Flutter code for portfolio review. They demonstrate:

- a deliberately small application entry point;
- lifecycle-aware application state;
- feature composition for the main dashboard;
- domain modeling and testable cat-approval logic;
- custom-painted usage charts;
- widget tests driven through a mocked native method channel.

They are provided as readable samples and do not form a standalone build. Native app interception, Firebase transport, cloud functions, credentials, signing material, proprietary assets, and the remainder of the production source are intentionally excluded.
